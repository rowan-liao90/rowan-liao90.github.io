## 先讲一个故事

帮一家企业做AI客服，上线前我问："数据准备好了吗？"

老板说："准备好了，我们有10年的客服记录。"

我说："那太好了，给我看看。"

打开一看：
- 有些记录是文本，有些是图片，有些是语音
- 文本格式不统一，有长有短，有规范有不规范
- 同一个问题有几十种问法，没有标注"这是同一个问题"
- 还有大量的"无意义对话"（问候、寒暄、重复）

老板问："这些能用吗？"

我说："能用。但要先花3个月做数据治理。"

老板说："3个月？AI不是号称智能吗？"

我说："**AI靠数据喂养，没有好数据就没有好AI。**"

## 数据治理的三个层次

### 层次一：数据资产盘点

**核心问题：我们有什么数据？**

#### 盘点维度

| 维度 | 说明 | 关键问题 |
|------|------|---------|
| 数据类型 | 结构化/非结构化 | 有多少非结构化数据？ |
| 数据来源 | 业务系统/外部数据 | 数据在哪些系统里？ |
| 数据量级 | 条数/存储量 | 数据量够不够？ |
| 数据质量 | 完整性/准确性/一致性 | 数据质量怎么样？ |
| 数据时效 | 实时/准实时/历史 | 数据有多新？ |
| 数据权限 | 谁能访问/谁能修改 | 数据安全吗？ |

#### 盘点工具

- 数据字典：描述每个数据字段的含义
- 数据血缘图：描述数据之间的关联关系
- 数据地图：可视化展示数据资产全貌

### 层次二：数据质量提升

**核心问题：怎么让数据"好用"？**

#### 数据质量问题类型

| 问题类型 | 说明 | 典型案例 |
|---------|------|---------|
| 完整性问题 | 数据缺失 | 字段为空、记录不完整 |
| 准确性问题 | 数据错误 | 输入错误、格式错误 |
| 一致性问题 | 数据矛盾 | 同一数据多个版本 |
| 时效性问题 | 数据过期 | 数据太久没更新 |
| 唯一性问题 | 数据重复 | 重复记录、重复字段 |

#### 数据质量提升方法

**方法1：数据清洗**
- 缺失值处理：删除/填充/预测
- 异常值处理：识别/修正/删除
- 重复值处理：识别/合并/删除

**方法2：数据标准化**
- 格式统一：大写/小写、日期格式、编码规范
- 语义统一：同义词归一、度量单位统一
- 编码统一：建立统一的编码体系

**方法3：数据标注**
- 分类标注：标注数据属于哪个类别
- 实体标注：标注数据中的关键实体
- 关系标注：标注实体之间的关系

### 层次三：数据资产管理

**核心问题：怎么让数据"持续好用"？**

#### 数据资产管理框架

| 维度 | 内容 | 关键动作 |
|------|------|---------|
| 数据标准 | 字段定义、格式规范 | 建立标准文档 |
| 数据安全 | 权限管理、加密脱敏 | 权限分级、审计日志 |
| 数据成本 | 存储成本、计算成本 | 成本核算、优化存储 |
| 数据价值 | 使用频率、业务价值 | 价值评估、优先级排序 |

#### 数据治理组织保障

| 角色 | 职责 |
|------|------|
| 数据Owner | 对某个数据域负责，决定数据怎么用 |
| 数据管理员 | 负责数据日常维护和质量监控 |
| 数据分析师 | 使用数据，支持业务决策 |
| 数据工程师 | 负责数据平台和技术架构 |

## AI场景的数据准备

### 场景1：智能客服

**需要什么数据**：
- 历史对话记录：客服和客户的对话
- FAQ知识库：常见问题和标准答案
- 业务知识库：产品、政策、流程等知识

**数据准备要点**：
| 步骤 | 要点 |
|------|------|
| 数据清洗 | 去掉无意义对话、合并重复问题 |
| 问题归一 | 把不同问法归到同一个问题 |
| 答案标注 | 标注标准答案、补充答案 |
| 意图标注 | 标注用户意图、情感倾向 |

**数据质量标准**：
- 对话记录：至少1000条/场景
- 问题覆盖：至少覆盖80%的常见问题
- 标注准确率：>95%

### 场景2：AI质检

**需要什么数据**：
- 产品图片：合格品和不合格品图片
- 缺陷标注：图片中标明缺陷位置和类型
- 工艺参数：生产过程中的关键参数

**数据准备要点**：
| 步骤 | 要点 |
|------|------|
| 样本采集 | 覆盖各种光线、角度、背景 |
| 缺陷标注 | 专业人员在图片上标注缺陷 |
| 质量验证 | 多人标注，验证一致性 |
| 样本平衡 | 正负样本比例合理 |

**数据质量标准**：
- 图片数量：至少1000张/缺陷类型
- 标注准确率：>95%
- 正负样本比例：1:1 到 1:3

### 场景3：智能风控

**需要什么数据**：
- 客户画像：人口统计、行为数据、信用数据
- 交易记录：历史交易、异常交易
- 标签数据：违约客户、欺诈案件

**数据准备要点**：
| 步骤 | 要点 |
|------|------|
| 数据整合 | 整合多源数据，建立客户视图 |
| 特征工程 | 从原始数据中提取风控特征 |
| 标签构建 | 构建标签：好客户/坏客户 |
| 数据脱敏 | 敏感数据脱敏，保护隐私 |

**数据质量标准**：
- 数据完整性：>90%
- 标签准确率：>95%
- 数据时效：T+1或实时

## 数据治理的常见坑

### 坑1：数据很多，但质量很差

**表现**：数据量大，但"垃圾进、垃圾出"

**后果**：AI模型效果差，项目失败

**避坑**：先做数据质量评估，再决定要不要上AI

### 坑2：数据分散，没有打通

**表现**：数据在各个系统里，互不打通

**后果**：AI只能用到部分数据，效果有限

**避坑**：先做数据打通，再上AI应用

### 坑3：只做一次，不持续维护

**表现**：数据治理做了一次，之后就不管了

**后果**：数据质量逐渐下降，AI效果越来越差

**避坑**：建立持续的数据治理机制

### 坑4：重技术轻治理

**表现**：关注数据平台建设，忽视数据质量管理

**后果**：平台建好了，数据还是不能用

**避坑**：数据治理和技术平台并重

## 数据治理的里程碑

| 阶段 | 时间 | 关键动作 | 验收标准 |
|------|------|---------|---------|
| 资产盘点 | 1-2周 | 数据资产梳理、形成数据地图 | 数据资产清单完成 |
| 质量评估 | 1-2周 | 数据质量评估、问题识别 | 数据质量报告完成 |

| 平台建设 | 2-4个月 | 数据平台、治理工具 | 平台上线、稳定运行 |
| 持续运营 | 持续 | 持续监控、持续优化 | 数据质量保持 |

## 核心判断

> **数据治理是AI落地的根基工程。** 没有数据质量，就没有AI质量。数据治理做不好，AI项目大概率会失败。
>
> 记住九个字：**不着急，不害怕，不要脸。**
> - **不着急**：数据治理需要时间，别想着一蹴而就
> - **不害怕**：数据问题复杂，但可以逐步解决
> - **不要脸**：不懂数据就问，问清楚了再动手

## FAQ

**Q: 数据不够怎么办？**
A: 数据不够分两种情况：一种是"数据有但没整理"，先做数据治理；另一种是"数据确实少"，选对数据依赖低的AI场景，或者先积累数据。

**Q: 数据治理要花多长时间？**
A: 看数据基础和场景复杂度。简单的数据清洗1-2个月，复杂的数据治理6-12个月。

**Q: 怎么评估数据质量？**
A: 用"完整性、准确性、一致性、时效性、唯一性"五个维度来评估。每个维度打分，综合得分就是数据质量得分。
